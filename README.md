# Street Games

Home page for three street-sport browser games, built as tiny clay worlds with Three.js.

**Play:** https://muhammadalims.github.io/

| Game | Sport | Play | Code |
|---|---|---|---|
| Galli Cricket | Street cricket (India) | https://muhammadalims.github.io/galli-cricket/ | [galli-cricket](https://github.com/MuhammadaliMS/galli-cricket) |
| Panna Cage | Street football (London, Rio, Paris) | https://muhammadalims.github.io/panna-cage/ | [panna-cage](https://github.com/MuhammadaliMS/panna-cage) |
| Block Hoops | Streetball (NYC, Manila, Venice Beach) | https://muhammadalims.github.io/block-hoops/ | [block-hoops](https://github.com/MuhammadaliMS/block-hoops) |

Each game lives in its own repository and is served at its own path on the same site, so this repository only holds the home page (`index.html`) and its screenshots (`img/`).
